# Daily Puzzle

A quick game concept with one five-letter word to guess each day.

## How to play

- Guess a five-letter word in six attempts.
- Green means a letter is in the correct position.
- Yellow means a letter belongs elsewhere in the word.
- Gray means the letter is absent, or exceeds its count in the answer.

## First version

A small word list, an on-screen keyboard, and a daily answer selected by date. Save progress locally.

## Optional Solana idea

A future devnet prototype could record a completion badge. Keep guesses and gameplay off-chain.
